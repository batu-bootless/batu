# USMLE landing page clone

A static HTML/CSS/JS recreation of the layout and visual design of
https://medical.uworld.com/usmle/ (sampled Nov 2026), built as a design study.

- Brand is swapped for the placeholder **MedPrep**, and the original's product
  screenshots and illustrations are rebuilt in CSS/SVG instead of copied.
- Fonts: Figtree (Google Fonts) stands in for the original's licensed Proxima Nova.
- Colors, type sizes, spacing and section order match the reference's computed styles.

Open `index.html` directly in a browser — no build step.

Files: `index.html` (markup), `styles.css` (tokens + layout + responsive), `script.js`
(mobile nav, carousels with arrows/dots/autoplay).
